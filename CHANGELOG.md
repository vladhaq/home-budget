# История версий

## 1.2.0 — 2026-10-03

- **Аналитика** — новый раздел: прогноз месяца по группам категорий (потрачено + регулярные платежи, которые
  ещё ждём, + обычные траты оставшихся дней по медиане), календарь ожидаемых платежей и поступлений с остатком
  на счёте, регулярные платежи и поступления, найденные по выписке и заказам (с отметками «регулярное» / «нет»).
- **Скидки:** вкладки Lidl и **Kaufland** (газетки Kaufland), у каждого магазина свои постоянные позиции;
  вкладка **«Где выгоднее»** — одинаковое в обоих магазинах (мясо по видам за кг, одна марка, свои позиции);
  история цен и личная инфляция — и по чекам, не только по газеткам; «обычно платишь» — медиана, сравнение за кг/л.
- **Обзор:** глаз у категории и подкатегории — убрать её из графика и сводки.
- **Наличные:** карточка «всего: наличные + на счёте».
- **Почта:** больше форматов писем — таблица «Produkt / Ilość / Kwota», блоки «марка / название / Ilość»,
  магазины на IdoSell, DOZ «1 / x цена», запись к врачу; скидка на заказ делится по позициям; «Kwota VAT» —
  не итог. Описание платежа PayU/Przelewy24 — название позиции, а номер заказа в нём связывает оплату с письмом
  магазина. Письма — с начала банковской выписки.
- **Сверка:** номер операции BLIK из писем Tpay — точное совпадение с выпиской; номер транзакции посредника —
  не из подвала письма (там KRS, один на все платежи); письма посредников не теряются из-за операции банка
  той же суммы; возврат всего заказа из нескольких товаров — «… и ещё N».
- Новая колонка базы `pay_ref` — миграция при первом запуске.

## 1.1.0 — 2026-10-02

- **Категории перестроены:** у системных категорий постоянный ключ (переименование и перенос в интерфейсе
  ничего не ломают); новые подкатегории — «Сладкая выпечка», «Бытовая техника», «Поезда и междугородние»,
  «Продукты без чека», «Семья», «Долги и возвраты»; слиты мелкие («Мясо и рыба», «Овощи и фрукты»,
  «Молочное и яйца», «Ремонт и инструменты»). Старые базы перестраиваются сами при первом запуске.
- **Возвраты** на карту связаны с исходной покупкой: показываются внутри неё и получают её категорию
  (в т.ч. возврат одного товара из заказа и возврат в тот же день).
- **Платежи под вопросом:** регистрация платежа в Przelewy24/PayU без подтверждения, которой нет в выписке,
  в суммы не идёт — очередь на странице «Неопознанные» с кнопками «оплачено» / удалить.
- **Правила по магазину и получателю:** «все покупки в ALDI», «все переводы этому человеку» —
  для операций банка вместо правил по уникальному названию; внутри чеков словарь товаров главнее.
- **Свои правила — в config.ini** (работодатель, вуз, свои заведения, города): в коде только общие.
- **Банк:** правила понимают описание, где город склеен с названием; назначение перевода на телефон
  («KINO», «ZWROT») учитывается; подписки раньше операторов связи.
- **Сверка повторяемая:** суммы из чека хранятся, пересборка источников отдельно от сверки.
- **Обзор:** расходы, поступления (доходы и входящие переводы из выписки) или оба сразу — с разницей «получил /
  потратил»; день / неделя / месяц / квартал / год, двойной клик — уровень глубже.
- **Фильтр категорий** — можно выбрать несколько сразу (например, «Еда» и «Табак и вейп»).
- **Банк:** операция раскрывается — что в выписке, откуда покупка, все позиции с категориями, чеки в эти дни;
  у поступления — сколько всего пришло от этого отправителя.
- **Почта:** письма Allegro «Zapłaciłeś … za:» (оплата позже покупки) и Allegro Lokalnie.
- **Наличные:** взнос на счёт — доход («получил / потратил»).
- **Безопасность интерфейса:** только localhost (проверка Host), команды — только JSON-запросами.
- **Проверки:** тесты словаря (`python -m pytest`) и снимок категорий «было → стало» (`tools/catsnap.py`).

## 1.0.0 — 2026-10-01

Первая версия.

- **Покупки до отдельных товаров:** электронные чеки Lidl Plus и Kaufland Card, онлайн-заказы из Gmail
  (Allegro, Koleo, DOZ, Media Expert, квитанции Stripe…), фото и сканы бумажных чеков — из Telegram-группы
  или папки, распознавание Tesseract с перепроверкой EasyOCR. Фото чека, который уже есть в электронном виде,
  прикрепляется к нему, а не создаёт дубль.
- **Банк:** выписка PKO BP через Enable Banking (только чтение), сверка покупок с операциями, в том числе
  несколько заказов одной операцией и оплата при получении; способ оплаты — из выписки.
- **Категории:** дерево, словарь польских названий, правила, комментарии к позициям («что купил») —
  категория определяется и по ним.
- **Деньги:** доходы и баланс, наличные на руках (пересчёт, взносы и снятия из выписки), удалённые покупки.
- **Скидки Lidl:** газетки, постоянные позиции, поиск, напоминания в Telegram накануне акции,
  история цен, инфляция по корзине.
- **Обслуживание:** «обновить всё» одной командой и автозапуск через Планировщик Windows, журнал,
  зашифрованные резервные копии (AES-256).
- **Интерфейс** на localhost в стиле Telegram: светлая и тёмная тема, анимации, поиск, вкладка «Настройки».
