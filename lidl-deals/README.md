# Lidl.pl — скидки на нужные товары + напоминания в Telegram

> Всё это есть и в интерфейсе бюджета: вкладка **«Скидки»** (`python budget.py serve`), а газетки и напоминания
> по постоянным позициям обновляются в «обновить всё». Вход в Telegram там общий с фото чеков (`python budget.py telegram`).
> Ниже — как пользоваться модулем отдельно, из терминала.

Скрипт скачивает актуальные газетки Lidl (PDF и API `leaflets.schwarz`, те же, что на lidl.pl/c/nasze-gazetki),
ищет в них товар и ставит отложенное сообщение в **Избранное** Telegram накануне начала акции.

## Установка (один раз)

```
pip install -r requirements.txt
copy config.ini.example config.ini
```

В `config.ini` впиши `api_id` и `api_hash` с https://my.telegram.org (API development tools).
При первом напоминании Telethon спросит в терминале номер телефона и код из Telegram
и сохранит сессию в `data/telegram.session`. **Этот файл — полный доступ к аккаунту, никому не отдавай.**

## Использование

```
python lidl.py
```
Если индекс старше суток, скрипт обновит газетки и покажет меню:

```
1 — постоянные позиции (4: maslo, kawa ziarnista, ...)
2 — найти товар
3 — редактировать список постоянных позиций
```

- **Постоянные позиции** хранятся в файле `постоянные_позиции.txt`: один товар на строку,
  строки с `#` игнорируются. Пункт 1 проверяет их все разом, пункт 3 открывает файл в Блокноте.
  В поиске (пункт 2) можно ввести `+товар`, чтобы сразу добавить его в постоянные.
- **Найти товар.** Пиши по-польски, диакритику можно не ставить (`maslo`, `piers z kurczaka`).

У каждого результата есть метка времени: «идёт, до 03.10 сб», «идёт — последний день сегодня!»,
«начнётся завтра, 01.10 чт». Акции вида «6 + 6 gratis» или «2 + 1 za grosz» пересчитываются
в реальную скидку и цену за штуку.

После результатов введи номера (`1,3`) или `all`, и в Избранном появятся напоминания:
- акция ещё не началась: сообщение придёт накануне в `remind_hour`;
- уже идёт: сообщение придёт сразу.

Повторно по одному и тому же товару напоминание не ставится (см. `data/reminders.json`).

Команды без меню:
```
python lidl.py search maslo
python lidl.py update
python lidl.py watch add "kawa ziarnista"   # добавить в постоянные позиции
python lidl.py watch ls
python lidl.py auto                         # обновить + проверить постоянные позиции + поставить напоминания
```

## История цен, инфляция, сезонность

При каждом обновлении все товары из газеток записываются в `data/price_history.json`: цена, обычная цена,
процент скидки, размер упаковки и цена за кг/л (обычная и по акции).

- Пункт меню **4** (`python lidl.py history maslo`) выводит таблицу по датам, изменение обычной цены,
  лучшую акционную цену, акции по месяцам и HTML-график (синяя линия — обычная цена, красные точки — акции).
- Пункт меню **5** (`python lidl.py report`) — это инфляция по постоянным позициям: было → стало по каждому
  товару и в среднем по корзине, плюс графики и сезонность в `data/report.html`.

Для инфляции берётся цена за кг/л, если она есть: так видно и уменьшение упаковки при той же цене.
Сравнения появятся через пару недель, сезонность — через несколько месяцев. Чтобы в истории не было дыр,
скрипт должен запускаться на каждую новую газетку, лучше всего через автозапуск `auto` (см. ниже).
Для графиков нужен интернет: библиотека Chart.js грузится с CDN.

## Автозапуск (по желанию)

Lidl выпускает продуктовые газетки дважды в неделю (с понедельника и с четверга), поэтому `auto`
лучше запускать 2 раза: в воскресенье и в среду.

```
schtasks /Create /TN "Lidl deals Sun" /SC WEEKLY /D SUN /ST 10:00 /TR "python C:\путь\к\проекту\lidl-deals\lidl.py auto"
schtasks /Create /TN "Lidl deals Wed" /SC WEEKLY /D WED /ST 10:00 /TR "python C:\путь\к\проекту\lidl-deals\lidl.py auto"
```
Сначала один раз запусти скрипт вручную, чтобы войти в Telegram.

## Ограничения

- Только продукты: непродуктовые каталоги Lidl не скачиваются, товары марок Silvercrest/Parkside/Livarno/...
  и корм для животных отсеиваются (список `NON_FOOD` в `lidl.py`). Каталоги вина и алкоголя оставлены.
- Если цены нет (акции вида «второй товар −30%»), показывается процент скидки.
- Если у товара в газетке нет «najniższa cena z 30 dni» или «cena przed obniżką», юридически это не скидка,
  а обычная цена (часто с плашкой «Supercena»). Такие товары помечаются. При каждом обновлении
  цены всех товаров газетки пишутся в `data/price_history.json`. Когда товар встретится снова,
  скрипт покажет цену из прошлой газетки и разницу в %.

- Цены берутся из текста PDF. Если цена нарисована картинкой, она считается из «старой цены» и % скидки
  и помечается `≈`. Если не распознано ничего, есть ссылка на страницу газетки.
- Акции с купоном Lidl Plus отмечены отдельно: купон надо активировать в приложении.
- Если Lidl поменяет формат газеток, парсер может сломаться.
